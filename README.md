Descripcion: 
La página web de BrisaWeb es la interfaz principal donde los usuarios pueden interactuar con el sistema de análisis de retinas. Diseñada con un enfoque en la simplicidad y usabilidad, permite a los usuarios gestionar su información y resultados de manera eficiente.

Características clave
Autenticación de usuarios:

Registro seguro con validación de datos.
Inicio de sesión para acceder a las funcionalidades.
Gestión de imágenes:

Subida de imágenes para su análisis por el sistema de inteligencia artificial.
Visualización de un historial de imágenes con resultados asociados.
Resultados detallados:

Visualización de los diagnósticos proporcionados por las APIs de análisis.
Indicaciones claras sobre posibles enfermedades detectadas.
Gestión de perfil:

Actualización de información personal, como correo electrónico, nombre de usuario y contraseña.
Interfaz interactiva:

Navegación intuitiva y diseño responsivo para una experiencia fluida en dispositivos de escritorio y móviles.
Tecnologías utilizadas
React + Vite: Para un desarrollo rápido y eficiente de la interfaz.
React Router: Para la navegación entre diferentes páginas.
Axios: Para realizar solicitudes HTTP al backend.
